# Skill与机器接续

## 接入方式

本包Skills随河图插件注册，外部Codex经同一稳定CLI/MCP即时发现`skills.read`，读取`hetu-picturebook`入口及按需参考。不向Codex安装同名插件，不增加永久客户端工具名，安装生命周期与作品管理连接分开。

## 默认旅程

读取固定故事与图像→组织页序和翻页意图→编排图文框→跨页通读→检查实际字体与图片→表达固定页意见→返工新修订→导出HTML与PDF。

方法入口为[SKILL](../skills/hetu-picturebook/SKILL.md)，[操作地图](../skills/hetu-picturebook/references/operations.md)随清单生成，[流程](../skills/hetu-picturebook/references/workflows.md)描述专业决策。

## 有界发现与内容

先发现当前包摘要与专业Schema，再精确读取必要宿主动作。不全量加载所有插件方法，不用压缩摘要冒充已读原文。大成果使用summary与固定分块完整核验；只读投影不改变写入原输入。

## 恢复与用户决定

未知写入先查原键；同输入明确未落盘才恢复，不换键重复写入。CAS冲突保留输入。Agent执行准备与确定性事务，作者保留采纳、定稿、费用和外发决定。正文与固定图像归宿主。本包维护最多32页的绘本专业工程；读取PNG/JPEG，图像合计8MiB、单图2MiB。导出RGB PDF与离线HTML，嵌入固定中文字体。毫米、出血、安全区与实际字体度量可验证；不承诺印厂认证、CMYK/PDF-X、儿童理解程度或生成质量。缺图、缺页、文字溢出及缺字阻止PDF交付。
