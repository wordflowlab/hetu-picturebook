# 用户用例与验收矩阵

## 用户故事

绘本的意义来自文字、画面和翻页的协作。把每页当成一次独立生成，会丢失页序、跨页关系和印刷尺寸。作者需要在整本中审阅节奏，而不是反复搭建排版。固定版面承担确定性计算，Agent负责理解与创作。

作者说出目标，Codex发现能力、读取固定资料并准备成果；作者阅读与表达意见，下一轮保留旧依据。

## 测试分层

单元测试验证专业计算与反例，Schema测试验证闭合输入，CLI/MCP验证Core归属及事务，Electron验证真实阅读／播放和交互，当前Codex连接验证热发现和方法可读。正式安装包、源码构建、跨平台及创作品质分别记载，不互相替代。

联合旅程使用隔离原创样本，覆盖固定故事→绘本跨页→局部返工、固定原著→分角色资料→试玩复盘→宿主候选。原作摘要保持，外部发送和付费工具不自动触发。
